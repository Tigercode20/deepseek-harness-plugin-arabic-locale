# dsh-plugin-arabic-locale

حزمة لغة عربية (من اليمين إلى اليسار) لواجهة **DeepSeek Harness**.

تضيف **العربية** إلى *الإعدادات ← عام ← اللغة*، وتترجم الواجهة، وتقلب اتجاه المستند
إلى `dir="rtl"` أثناء تفعيل العربية.

[English](README.md) · العربية

---

## ماذا تفعل

| الجزء | السلوك |
| --- | --- |
| قائمة اللغات | تسجّل `ar` بالاسم **العربية**، مع الرجوع للإنجليزية |
| نصوص الواجهة | قواميس عربية لكل الفضاءات الاسمية التي يشحنها DSH |
| اتجاه المستند | `<html dir="rtl">` أثناء اختيار العربية، ويُرجَع عند اختيار لغة أخرى |
| الرجوع الجزئي | مفتاح بمفتاح: أي مفتاح غير مترجم يظهر بالإنجليزية — لا مفتاح خام ولا نص فارغ |

### التغطية

مقيسة مقابل قاموس `en` في كل حزمة:

| | |
| --- | --- |
| نصوص الواجهة الإنجليزية | **1,793** |
| المترجم هنا | **1,787** (99.7%) |
| عدد الفضاءات الاسمية | **29** |
| غير مترجم عن قصد | رموز الأوامر الستة (`goal`, `plan`, `feedback`, `compact`, `permission`, `export`) لأنها نص يكتبه المستخدم بعد `/` |

### ما تم التحقق منه

- **2,069 تست** في `@deepseek-ai/dsh-client-ui-primitives` تمرّ مع تعديل العرض المرافق.
- الحزمة مُجرَّبة عبر محمّل وهمي: تسجّل اللغة و29 قاموسًا، وتقلب `dir` إلى `rtl` مع العربية وترجعه مع غيرها.
- التغطية مقارنة برمجيًا بمفاتيح `en` في كل حزمة، بلا مفاتيح زائدة.

**ما لم يُتحقق منه:** الصفحة المعروضة فعليًا. لم يتوفر تحكّم في متصفح في بيئة البناء،
فالشكل النهائي — خاصة سلوك الواجهة الإنجليزية عند قلب المستند — يحتاج فحصًا بشريًا.
افتح Issue مع صورة شاشة إن ظهر خلل.

## التثبيت

```bash
dsh plugin add dsh-plugin-arabic-locale
# أو من مستودع GitHub
dsh plugin add https://github.com/<you>/dsh-plugin-arabic-locale
```

أو من التطبيق: **Plugins ← Add plugin** ثم اسم الحزمة أو مسار المجلد المحلي.

بعد التثبيت: **الإعدادات ← عام ← اللغة ← العربية**.

## تصحيح العرض المرافق (RTL)

الترجمة وحدها لا تكفي: عارض Markdown ومربع الكتابة والفقاعات كلها مبنية للاتجاه
اليساري فقط. التصحيح موجود في:

```
patches/dsh-core-rtl.patch
```

يغيّر خمسة ملفات تحت `packages/client/**`: `dir="auto"` للكتل، خصائص CSS منطقية،
عزل الكود باتجاه `ltr`، وارتفاع سطر أطول للعربي.

```bash
git clone https://github.com/deepseek-ai/deepseek-harness
cd deepseek-harness
git apply /path/to/patches/dsh-core-rtl.patch
pnpm exec vitest run -u packages/client/ui-primitives/tests/markdown-dom-parity.client.spec.tsx
pnpm run build:lib:client
```

المشروع الأصلي يذكر في `CONTRIBUTING.md` أنه لا يقبل Pull Requests خارجية حاليًا،
لذلك يُشحن التصحيح كـ patch يُطبَّق على نسختك.

## التوسّع

كل القواميس في `client.js` داخل كائن `dictionaries` مفهرس بالفضاء الاسمي.
أضف المفاتيح التي تحتاجها وحافظ على العناصر البديلة (`{name}`, `{count}`, …) كما هي.
لا يوجد خطوة بناء: `client.js` هو وحدة المتصفح المشحونة.

## التوافق

- مبني ومُتحقَّق منه على **DSH 0.2.2-rc.3**.
- يسجّل عبر واجهة `ctx.locale.addLanguage` و`ctx.locale.register` العامة.
- بلا اعتماديات وبلا سكربتات تثبيت.
